# 渠道图标来源

这些品牌图标只用于标识对应渠道，商标权归各品牌所有。资源随前端本地打包；页面不依赖外部 CDN，不通过用户凭据下载图标。

## LobeHub

以下 SVG 原样取自 [Lobe Icons](https://icons.lobehub.com/) 的官方静态包 `@lobehub/icons-static-svg@1.102.0`，下载时按包目录提供的 SHA-256 integrity 校验。MIT 许可证保留于 [LICENSE.lobehub](LICENSE.lobehub)。原始链接和文件摘要记录于 [sources.json](sources.json)。

生产构建同时包含 `public/assets/third-party-notices.txt`，部署后可通过 `/assets/third-party-notices.txt` 查看图标许可与来源说明。

## OpenDesign

LobeHub 当前未收录 OpenDesign。`opendesign.png` 为 [OpenDesign 官网](https://open-design.ai/) 页面声明的 180px `apple-touch-icon`，按官网原始资源保留，不冒用 LobeHub 的 MIT 许可证。仅用于本项目中识别 OpenDesign 服务；其商标与图形权利归 OpenDesign 所有。

两类来源均不包含脚本或运行时外部引用。单色版本通过页面样式适配深色主题，彩色版本保留品牌颜色。
