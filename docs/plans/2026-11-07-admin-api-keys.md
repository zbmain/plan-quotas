# 管理面板与 API Key 改造验收

2026-11-07。software 控制台，保留既有翡翠绿、深浅主题及本地字体。本次基于当前工作区实施，没有提交 Git、发布部署或修改实际部署数据。

## 完成行为

- 后台顺序为：渠道账号、页面设置、数据采集、访问权限、API 接入、MCP 接入、联网搜索。
- 访问方式显式保存；服务端生成 `sk-` + 32 字节密码学随机量的 Base64url Token，最多 5 个，并发申请不能突破上限。
- 列表和申请响应仅返回 ID、创建时间等元数据。主动点击眼睛或复制时，才通过管理员会话与 CSRF 保护的接口读取明文；查看逐行独立、复制不展开，离页及刷新后清除。
- API/MCP 仅以 `apikey` 请求头或查询参数鉴权，旧密码、`password`、`X-API-Password`、Bearer 不再授予接口权限。公开仪表盘、管理员登录和配额 JSON 结构保持原有行为。
- Token 与访问方式独立加密保存至 `api-access.enc`，使用原 `master.key`、AES-256-GCM 和独立 AAD。撤销立即生效，不通过旧备份恢复已撤销 Token；访问文件或主密钥缺失、损坏时拒绝启动。
- 原免密实例保持免密；原密码保护实例保持密钥模式，等待管理员申请 Token 并更新客户端。
- MCP 模板默认折叠，点击“配置示例”才显示格式化代码块；复制内容与显示一致，示例仅包含占位符。
- 联网搜索只显示已配置且支持搜索的账号，保留优先级和暂停说明。勾选即时保存，成功后局部更新；保存期间禁止重复操作，失败保留原状态。

## ego-browser 实际验收

使用临时隔离服务和合成账号，不请求真实供应商或消耗搜索额度。TaskSpace 8，完成后关闭。

| 项目 | 结果 |
| --- | --- |
| 七板块顺序、搜索候选过滤 | 通过；未配置凭据和不支持搜索的账号不出现 |
| 无 Token 时启用密钥访问 | 显示申请提示，原免密方式未变 |
| 申请、默认遮罩、逐行查看、隐藏、复制 | 通过；复制不展开明文 |
| 五个上限 | 第五个创建后禁用申请，服务端并发测试同时覆盖 |
| 撤销 | 行移除，旧 Token 请求 `/info` 立即返回 401 |
| 页面离开、返回、刷新、pagehide | 已查看明文清除，访问方式和 Token 元数据保留 |
| 设置读取失败、重试 | 显示错误及重试按钮，不误展示免密请求示例，重试恢复 |
| MCP 模板 | 默认收起，展开可解析 JSON，使用 apikey 占位符，复制完全一致，再次点击收起 |
| 搜索开关 | 保存中禁用，模拟 503 时状态保持，成功后立即生效且刷新后保留 |

在 320、390、768、1024、1440px 检查，页面宽度均与视口一致，无横向溢出；所有 Token 操作按钮至少 44×44px。窄屏代码块使用自身 `overflow-x: auto`，长 Token 换行显示。

本次为工作台设置界面，沿用已确认的 taste-skill 适配：按内容自然排版；营销页专属的首屏 Hero、每节整屏高度及摄影要求不适用。新界面沿用统一设计变量、细边框、4/6/8px 圆角及现有减少动态效果规则。
